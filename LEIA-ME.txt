LC Gestor - Bridge SQL
======================
Versao 1.2 | LC Tecnologias

O que e isso?
-------------
Este programa conecta o dashboard LC Gestor ao SQL Server desta maquina.
Ele roda em segundo plano e responde apenas a consultas autorizadas do sistema.

Como instalar
-------------
1. Copie esta pasta inteira (lc-sql-bridge) para este PC.
   Sugestao de local: C:\LC\lc-sql-bridge\

2. De duplo clique em LCBRIDGE-INSTALL.exe
   - O Windows pedira confirmacao de Administrador. Clique em "Sim".
   - Siga as instrucoes na tela (nome do cliente, banco de dados).
   - Ao final, copie o TOKEN exibido e informe ao suporte da LC Tecnologias.

3. Aguarde o suporte configurar o acesso no painel do LC Gestor.

O que o instalador faz automaticamente
---------------------------------------
- Instala o Node.js se nao estiver presente
- Instala as dependencias do programa
- Cria o usuario SQL lc_dashboard (somente leitura)
- Cria um .env com as configuracoes e token de seguranca
- Registra o servico para iniciar automaticamente com o Windows

Requisitos
----------
- Windows 10 ou superior (64 bits)
- Acesso de Administrador local
- Conexao com a internet (para instalar Node.js se necessario)
- SQL Server acessivel localmente (porta 1433)

Arquivos desta pasta
---------------------
LCBRIDGE-INSTALL.exe          -> Duplo clique para instalar (use sempre este)
INSTALAR.bat          -> Alternativa caso o .exe nao funcione
iniciar-bridge.ps1    -> Inicia manualmente (caso necessario)
desinstalar-bridge.ps1-> Remove o servico desta maquina
testar-bridge.ps1     -> Testa a conexao sem reinstalar
bridge.js             -> O programa em si (nao edite)
package.json          -> Dependencias do Node.js (nao edite)

Arquivos criados apos instalacao
---------------------------------
.env                  -> Token e credenciais (NUNCA compartilhe este arquivo)
node_modules/         -> Dependencias instaladas automaticamente
logs/                 -> Registros de atividade da bridge
configuracao-cliente.txt -> Resumo da instalacao (sem o token)

Desinstalar
-----------
Execute desinstalar-bridge.ps1 com o botao direito -> "Executar com PowerShell".
